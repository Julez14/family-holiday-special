# Implementation plan

The PRD and its companion decision record at the repository root are the product authority.

Build locally, with no deployment or paid inference. The repository began with only a README.

## Commit boundaries

1. Preserve the supplied requirements and establish the implementation plan.
2. Add the typed preset compiler, contracts, spending/retention policies, and toolchain.
3. Add D1/R2 ownership, draft/upload/description APIs, immutable job submission, sharing and cleanup.
4. Add durable workflow execution, fal queue/signature adapters, budgets, reconciliation and bounded repairs.
5. Add the native FFmpeg renderer, original illustrative fixtures, and media-contract verification.
6. Build and verify the responsive upload, personalization, progress and playback experience.
7. Finish integration/security checks, CI, setup documentation and implementation report.

## Skills

Installed before implementation from fal-ai-community/skills using the Codex skill installer:
fal-media, fal-video-production, video-compositing, fal-shot-craft, h3-cinematic-prompter.
Existing relevant skills: character-design, fal-prompting, model-routing, Cloudflare,
workers-best-practices and wrangler. Prompt guidance remains subordinate to the PRD's
fixed 2D cartoon style and music-only output.

## Evidence and gates

- Live fal schemas checked for GPT Image 2.6 Flare Edit, Nano Banana 2.1 Edit, H3 Max,
  Kling 4.0, and FFmpeg Compose. No generations were submitted.
- Compose exposes tracks/keyframes without explicit source-audio stripping,
  codec/frame-rate/size normalization, or fades. Select a single FFmpeg renderer
  rather than relying on undocumented controls. Verify with adversarial audio locally.
- Permissioned cast photographs, explicit real spending caps, cleared preset music,
  representative generated sample assets and the human quality pilot are not supplied.
  Mock fixtures must be explicitly identified and real mode must fail closed.
- Do not claim model comparisons or likeness benchmarks have happened.

See the final implementation report for completed checks and operator prerequisites.
